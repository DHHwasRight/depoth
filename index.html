Documentation

Getting started

What depoth isA static content framework in Rust, built on compiled templates and prerendered partial navigation.Installing depothA site is a Rust crate, so nothing is installed globally. You add three dependencies and build.Configurationdepoth.yaml, key by key: identity, directories, navigation, redirects, commands and bundles.

Writing

Writing contentFrontmatter keys, the markdown body, and how a mistake in a header reports a file, a line and a column.NavigationOne tree, declared outside the content, yielding the sidebar, the tab bar, breadcrumbs and prev/next.Layouts and templatesTemplates are rsx. They compile into the binary, which buys type checking and costs a rebuild.

Shipping

Partial navigationEvery route is prerendered as a document and as smaller trees, so a navigation replaces only what changed.Testing a built siteSix rules asserted over the output HTML in process, and the three claims that still need a browser.Deploying a siteBuilding for a static host, publishing to GitHub Pages, and serving the partial trees through nginx.
